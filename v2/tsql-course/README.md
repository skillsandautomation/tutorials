## What this course covers

- SELECT, FROM, and the basics of querying a table
- Filtering with WHERE, comparison operators, AND/OR, LIKE
- Sorting and limiting with ORDER BY and TOP
- Calculated columns and built-in functions (CONCAT, and more)
- Summarising data with GROUP BY and HAVING
- Combining tables with JOIN (INNER, LEFT, and beyond)
- NULL handling, subqueries, string/date functions, and more advanced topics as the series progresses
