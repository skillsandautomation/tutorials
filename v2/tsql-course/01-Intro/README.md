T-SQL for Business Professionals

Welcome to the GitHub repository for my T-SQL for Business Professionals YouTube course.

This course is designed for business professionals, analysts, finance professionals, reporting specialists, and anyone who works with data and wants to learn how to query relational databases directly using T-SQL.

No previous SQL or programming experience is required.

🎯 What You'll Learn

Throughout the course, we'll build from the fundamentals through to practical, real-world T-SQL skills, including:

Understanding relational databases, tables, keys, and relationships
Writing SELECT queries
Filtering data with WHERE
Sorting and transforming query results
Working with NULL values
Aggregating data with GROUP BY and HAVING
Combining tables using JOIN
Using subqueries and CTEs
Working with dates and text
Set operators and window functions
INSERT, UPDATE, and DELETE
Variables and temporary tables
Views, functions, and stored procedures
Error handling and transactions
Practical SQL Server and SSMS skills
🏢 Business-Focused SQL

The focus of this course is not simply learning SQL syntax.

We'll approach T-SQL from the perspective of someone working inside a business who needs to answer questions such as:

Which customers haven't ordered recently?

What are our highest-value products?

Which records have missing information?

How can I combine information stored across multiple tables?

The goal is to help you move from requesting data from the "backend" to being able to confidently query and analyse that data yourself.

🗄️ Course Environment

The course primarily uses:

Microsoft SQL Server
SQL Server Management Studio (SSMS)
AdventureWorks sample database

AdventureWorks gives us realistic tables covering areas such as customers, products, employees, and sales orders, allowing us to learn T-SQL using practical business scenarios.
