WebSockets in Excel VBA – Three Ways to Stream Live Data

Supporting files for the Skills and Automation YouTube tutorial demonstrating three approaches to streaming live market data into Excel using Alpaca's WebSocket API.

Included Files

PureVBA_modWebSocket.bas – VBA module using Windows' built-in WinHTTP WebSocket functions.

alpaca-bridge.ps1 – PowerShell script for receiving WebSocket messages outside Excel.

Web Socket Project - Blank.xlsm – Starter workbook for following the tutorial.

Web Socket Project - Final.xlsm – Completed workbook containing all three implementations: Pure VBA, Wasabi and PowerShell.

Getting Started

Download the files, open the Excel workbook and follow the video tutorial to configure your Alpaca API credentials and run the examples.

Note: The examples are intended for learning and demonstration purposes.
